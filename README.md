# KINGJOEBRIDD

A premium bespoke fashion and tailoring platform connecting customers directly with KINGJOEBRIDD.

## Stack
Frontend: Next.js + TypeScript + Tailwind CSS
Backend: Laravel + PHP
Database: Relational database

## Structure
```text
frontend/
backend/
docs/
```

## Development

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
composer install
php artisan serve
```
